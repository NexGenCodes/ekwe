# Security Policy

If you discover a security vulnerability in this project, please report it following the guidelines below.

Reporting
- Preferred: create a private issue addressed to the repository owners (or contact via the project's security contact).
- If you need to share sensitive proof-of-concept code or data, please use an encrypted channel.

Disclosure Timeline
- We will acknowledge receipt within 48 hours and attempt to provide a fix or mitigation within 14 days depending on severity.

Do not publish details publicly until a fix is available.
