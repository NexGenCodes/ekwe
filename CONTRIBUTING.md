# Contributing

Thank you for contributing!

Quick start:
- Fork the repo and create a feature branch from `main`.
- Ensure types pass: `npm run typecheck`.
- Lint and format: `npm run lint`.
- Run tests: `npm test`.
- Open a PR with a clear description of the change.

Pre-commit
- This repo uses `lint-staged` (configured in package.json). Use Husky (see README) to enable pre-commit hooks.
